# SynapseX landing page

React + TypeScript + Vite + Tailwind CSS + Framer Motion.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

- The hero video scrubs with horizontal mouse movement (sensitivity 0.8).
- Sections: Hero, Cinematic text, Metrics, Technology, Architecture, Footer.
- Fonts (Space Mono, Anton SC) and Bootstrap Icons load from CDNs in `src/index.css`.
